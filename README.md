- bootstrap

## ⚙️ Funcionalidades
- você ira clicar no botão da sua escolha e ira aparece a imagem diacordo com o que vc escolheu e IA detecta os objetos.

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/LauraCirino/Detecao-de-imagens
```

2. Abra o arquivo `index.html` em seu navegador.
